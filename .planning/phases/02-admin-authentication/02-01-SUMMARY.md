## Decisions Made
- Used `window.sessionStorage` (not `persistSession: false`) so auth session survives React re-renders and hot reloads but clears when the browser closes — `persistSession: false` would lose the session on hot reload which would be unusable in development
- Stripped the `AppSidebar` / `SidebarProvider` from the new `__guard/route.tsx` because Phase 2 scope is auth only; the admin layout shell belongs in Phase 3
- Replaced the old dashboard's `SidebarTrigger` / `Breadcrumb` components with a minimal centered placeholder since they depended on the sidebar context that was removed
