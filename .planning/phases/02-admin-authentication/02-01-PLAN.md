  <action>
    Update src/lib/supabase/client.ts to add the auth configuration block that switches storage from the default localStorage to window.sessionStorage. Keep all existing imports and the Database generic type.

    Replace the createClient call with:

    ```typescript
    export const supabase = createClient<Database>(
      env.VITE_SUPABASE_URL,
      env.VITE_SUPABASE_PUBLISHABLE_KEY,
      {
        auth: {
          storage: window.sessionStorage,
          persistSession: true,
          autoRefreshToken: true,
        },
      }
    )
    ```

    Why sessionStorage: The CONTEXT decision is "session persists until the browser is closed (not across browser restarts)". sessionStorage is cleared when the tab/browser closes, unlike localStorage which persists across restarts. Do NOT use `persistSession: false` (in-memory only — loses session on React re-render/hot reload).
